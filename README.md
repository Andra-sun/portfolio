# Este portfólio foi feito utilizando React. Para testá-lo localmente, siga os passos abaixo:  
---

### **Pré-requisitos**  
- Tenha o **Node.js** instalado em sua máquina. Caso já tenha, siga os próximos passos.  

### **1. Clonar o repositório**  
No terminal, abra a pasta onde deseja clonar o projeto e execute:  
```bash
git clone https://github.com/Andra-sun/portfolio.git
```

### **2. Acessar a pasta do projeto**  
```bash
cd portfolio
```

### **3. Instalar as dependências**  
```bash
npm install
```

### **4. Rodar o projeto**  
```bash
npm start
```

Após isso, o projeto estará rodando no seu navegador pelo link:  
[http://localhost:3000](http://localhost:3000)
